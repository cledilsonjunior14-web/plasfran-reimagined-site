## 3. FUNCIONALIDADES NECESSÁRIAS

### 3.1 Navegação

- Menu responsivo (mobile hamburger menu)

- Navegação fixa no topo (sticky header)

- Links internos para seções (âncoras)

- Links externos para WhatsApp e telefone

### 3.2 Carousels/Sliders

- Carousel de depoimentos (com navegação anterior/próxima)

- Carousel de despedidas recentes

- Indicadores de posição (dots)

### 3.3 Interatividade

- Botões com hover effects

- Links clicáveis para WhatsApp e telefone

- Botão "Acender Vela" (pode ser placeholder ou funcional)

- Botão "Novo depoimento" (pode redirecionar para formulário)

### 3.4 Responsividade

- Design mobile-first

- Breakpoints: mobile (320px), tablet (768px), desktop (1024px+)

- Imagens responsivas

- Menu adaptativo

### 3.5 SEO e Acessibilidade

- Títulos semânticos (H1, H2, H3)

- Meta tags (title, description)

- Alt text em imagens

- Contraste adequado de cores

- Links acessíveis

## 4. DESIGN E ESTILO

### 4.1 Paleta de Cores

- **Verde Profundo:** #1B5E3F (primária, confiança)

- **Verde Claro:** #2ECC71 (secundária)

- **Laranja/Teracota:** #FF6B35 (acentos, CTAs)

- **Branco:** #FFFFFF (fundo, texto)

- **Cinza Claro:** #F5F3F0 (fundos alternativos)

### 4.2 Tipografia

- **Títulos:** Fonte moderna e bold (ex: Poppins, Montserrat)

- **Corpo:** Fonte legível (ex: Inter, Roboto)

- **Tamanhos:** Hierarquia clara (H1: 48px, H2: 36px, H3: 24px, Body: 16px)

### 4.3 Elementos Visuais

- Formas orgânicas e arredondadas

- Ícones modernos

- Gradientes sutis

- Sombras suaves

- Espaçamento generoso

### 4.4 Animações

- Fade-in ao scroll

- Hover effects em botões e cards

- Transições suaves (300-500ms)

- Sem animações excessivas
